# Makeup By Sukh — Luxury Website v2

Upload `index.html` and the complete `assets` folder to the root of a public GitHub repository. In Settings → Pages choose Deploy from a branch, `main`, `/ (root)`.

The page includes responsive black/champagne styling, custom navigation, scroll-reveal animations, artist biography, all requested service categories, mobile artist positioning, hair and makeup inspiration URL fields, full mobile service address, and the $50 CAD and up non-refundable booking fee acknowledgement.

Email form is configured through FormSubmit for morethanmakeupbysukh@gmail.com. After publishing, submit a test and activate the receiving email if FormSubmit requests it. Test again before sharing with customers.

This is an enquiry form only; it does not take payment or reserve dates automatically. Confirm availability and exact booking fee in writing before collecting payment. Ensure fee/refund terms comply with applicable Alberta and Canadian consumer law.
